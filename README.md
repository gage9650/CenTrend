# 📖 프로젝트 소개

CentLand는 경제 초보자와 학생들이 어려운 경제 뉴스를 보다 쉽게 이해할 수 있도록 도와주는 **AI 기반 경제 학습 플랫폼**입니다.

기존의 경제 뉴스는 전문 용어와 복잡한 내용 때문에 진입 장벽이 높습니다.

CentLand는 AI를 활용하여 뉴스를 쉽게 요약하고, 경제 용어를 설명하며, 시각적인 콘텐츠와 학습 시스템을 제공하여 누구나 경제를 쉽고 재미있게 학습할 수 있도록 설계되었습니다.

# ✨ 주요 기능

## 📰 AI 뉴스 브리핑

- 오늘의 경제 뉴스를 AI가 요약
- 핵심 내용만 빠르게 확인
- 초보자도 이해하기 쉬운 설명 제공

---

## 📈 주식 상세 정보

- 관심 종목 확인
- 가격 변화 시각화
- 주가 차트 제공
- 종목별 상세 화면 제공

---

## 🎨 경제 뉴스 4컷 만화

복잡한 경제 뉴스를

✔ 만화 형식으로

✔ 쉽고 재미있게

학습할 수 있습니다.

---

## 🧠 경제 용어 학습

뉴스 속 어려운 용어를

즉시 확인하고 학습할 수 있습니다.

---

## 🎯 퀘스트 시스템

경제 공부를 게임처럼 즐길 수 있도록

- 퀘스트
- 경험치
- 레벨

시스템을 제공합니다.

---

## 🏆 랭킹 시스템

사용자의 학습 활동을 기반으로

랭킹을 제공합니다.

---

## 👤 사용자 프로필

- 학습 현황
- 레벨
- 활동 내역

을 관리할 수 있습니다.

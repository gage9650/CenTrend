# Solution

CenTrend(구 CentLand)는

학생의 관심 종목과 이해도에 맞춰 경제·시사 뉴스를 개인화하고,
읽는 데서 그치지 않고 **직접 예측하고 게임처럼 학습**하게 만드는
AI 기반 경제 학습 플랫폼입니다.

## 핵심 기능

### 📰 오늘의 AI 브리핑 (TodayBriefing)
- 관심 종목·카테고리 기반 뉴스 브리핑 제공
- 기사별 영향도(impactRating) 표시로 중요도를 한눈에 파악
- 주제/종목을 입력하면 AI(Gemini API 연동 서버)가 즉석에서 맞춤 브리핑을 생성

### 🎨 경제 뉴스 4컷 만화 (NewsComicModal)
- 어려운 뉴스를 4컷 만화 시나리오로 변환해 핵심만 빠르게 이해
- 컷마다 등장인물의 대사와 함께 핵심 용어(keyTerm)와 쉬운 설명을 제공
- 만화를 읽으면 XP가 적립되고, 좋아요·댓글로 반응 가능
- 마음에 든 만화는 버튼 한 번으로 커뮤니티에 공유

### 💬 커뮤니티 (CommunityView)
- 다른 사용자가 공유한 4컷 만화 요약을 모아보고 추천·댓글로 소통
- 인기 만화 / 개념 추천 / 기술 분석 등 카테고리 필터와 검색 지원

### 📈 실시간형 주식 상세 화면 (StockDetailView)
- 종목별 현재가·시가·고가·저가·거래량·시가총액·PER 등 상세 지표 제공
- 1일/1주/1개월/3개월/1년 기간별 차트(recharts) 지원
- Finnhub API 키가 설정되면 실제 시세를, 없으면 KRX 기준 시뮬레이션 파이프라인으로 안전하게 동작하며 데이터 출처를 화면에 투명하게 안내

### 🎯 뉴스 투자 예측 게임 (PredictionView) — v8 신규
- 실제 뉴스 기반으로 "오를지 내릴지" 방향을 맞히거나, 등락 폭(포인트)을 직접 예측
- 난이도(쉬움/보통/어려움), 종목별 필터 제공
- 예측 결과에 따라 점수·XP가 차등 지급되고, 오차 해설(explanation)로 왜 그런 변동이 있었는지 학습
- 정답률, 평균 오차, 연속 정답(streak) 등 개인 예측 통계를 누적 관리

### 🎯 퀘스트 & 뱃지 시스템 (QuestsView)
- 뉴스 예측 참여, 방향 맞추기, 연속 정답 등 조건에 따라 자동으로 진행도가 쌓이는 퀘스트
- 완료 시 XP 보상 지급, 레벨업 알림 제공
- 활동 기반으로 잠금 해제되는 뱃지 컬렉션

### 🏆 랭킹 시스템 (RankingView)
- XP와 예측 점수를 합산한 종합 점수로 전체 랭킹 제공
- 주간/월간/전체 기간 필터, 내 순위 하이라이트

### 👤 사용자 프로필 (ProfileView)
- 레벨, XP, 연속 학습일수(streak), 읽은 기사 수, 획득 뱃지 수 등 학습 현황 관리
- 관심 종목(관심사) 태그를 직접 추가/삭제하여 브리핑 개인화
- 개념별 이해도(GPU, ETF 등) 시각화
- 계정 데이터 초기화 기능(진행 데이터만 리셋, 로그인 상태는 유지) — 확인 모달(ResetConfirmModal)을 통한 안전한 초기화

### 🔐 로그인 & 랜딩 페이지
- 랜딩 페이지에서 서비스 소개 후 로그인 모달을 통해 진입
- 로그인 성공 시 개인화된 대시보드로 이동, 토스트 알림으로 즉각 피드백

## v7 대비 달라진 점

- Next.js/Supabase/OpenAI(예정) 기반 기획에서 **React 19 + Vite + Express + Gemini API** 실제 구현체로 전환
- "AI 투자 예측" 게임 요소가 기획 단계에서 실제 동작하는 핵심 기능으로 구현됨
- 주식 차트가 실제 API(Finnhub) 연동과 시뮬레이션 파이프라인을 함께 지원하는 형태로 구체화됨
- 랭킹이 XP + 예측 점수를 합산하는 종합 스코어 방식으로 설계됨
- 계정 초기화 등 실사용을 고려한 부가 기능 추가

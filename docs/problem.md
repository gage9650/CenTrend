# Problem

## 학생들은 경제와 투자 뉴스를 이해하기 어렵습니다.

경제와 투자에 대한 관심은 증가하고 있지만,
학생들이 접하는 뉴스는 전문 용어가 많고 내용이 길어
처음부터 끝까지 읽기 어려운 경우가 많습니다.

많은 학생들은

- 어디서부터 공부해야 하는지 모른다.
- 뉴스를 읽다가 중간에 포기한다.
- 어려운 용어 때문에 흥미를 잃는다.
- 투자에 관심은 있지만 시작하지 못한다.

결과적으로 경제 정보에 대한 접근성이 낮아지고,
투자에 대한 심리적 장벽은 더욱 높아집니다.


그리고

## 현재 대부분의 서비스는

- 뉴스를 단순 요약한다.
- AI 번역만 제공한다.
- 투자 정보를 나열한다.

하지만,

사용자가

<h3>"왜 이런 일이 일어났는지"</h3>

<h3>"과거에는 어떤 일이 있었는지"</h3>

<h3>"내 수준에서 이해했는지"</h3>

까지는 고려하지 않습니다.
